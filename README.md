# @it-service-npm/*-gfm-admonition micromark, mdast and remark plugins

This repository includes packages
that enhance the capabilities of micromark, mdast, and Remark.
They allow these tools to read GitHub admonitions
from Markdown files and write them back.

- [`@it-service-npm/micromark-extension-gfm-admonition`](/packages/micromark-extension-gfm-admonition/README.md)
- [`@it-service-npm/mdast-util-gfm-admonition`](/packages/mdast-util-gfm-admonition/README.md)
- [`@it-service-npm/remark-gfm-admonition`](/packages/remark-gfm-admonition/README.md)
